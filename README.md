# NVV Field Maps 1.0.84
Matches APK 1.0.84. Point, line/polyline, area, measurement, circle, selected-feature and vertex-edit trays have mouse/touch drag grips and remember positions. Point properties use a visual picker with 20 survey symbols, including source-icon preservation, live preview and Save/Cancel; symbol choices round-trip in NVV KML imports. Existing transmission lines now draw above opaque basemap tiles in the rotation container, with substations in the corresponding marker container, and remain visible through zoom/pan/rotation. Retains the supplied AP reference (1190 lines, 376 substations), root/folder visibility and device-local Delete, black project labels and existing survey functions. Run python3 build-web.py to verify baseline and overlays.
