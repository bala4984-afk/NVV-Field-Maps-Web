# NVV Field Maps 1.0.88
Matches APK 1.0.88. Vertex coordinates follow selected UTM, DMS or decimal-degree settings during selection and dragging. Includes live distances, DMS LT/RT angles and totals, continuous vertex insertion with Finish, Undo/Redo, Save/Cancel, and forest overlay visibility correction. Run python3 build-web.py to verify baseline and current source overlays.
