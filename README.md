# NVV Field Maps 1.0.83
Matches APK 1.0.83. Project names and map labels display in black while line and point-symbol colours retain their supplied styles; normal dialog/header colours are preserved. Dialog titles support mouse/touch dragging. Layers includes the supplied AP_TL_400_220_132kV.kml as a bundled reference: 1190 lines, 376 substations, 112716 vertices, six original voltage folders. Root and folder visibility persist on each device; Delete stays deleted on that device. The built-in layer starts Off to keep the survey map clear. Source geometry and cross-border continuations are retained as supplied. Reference data is separate from survey projects and exports. Run python3 build-web.py to verify baseline and current overlays.
