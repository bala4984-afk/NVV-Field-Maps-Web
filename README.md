# NVV Field Maps 1.0.85
Matches APK 1.0.85. Export a format, then choose Share or Save file. Supported browsers use file sharing; unsupported browsers retain downloads. Android 1.0.85 adds a native app chooser with read-only content-URI attachments for WhatsApp, email and other installed receivers. The native share provider requires the new 1.0.85 APK; a web-only update to an older APK does not add it. Copy selected points, lines, polylines or polygons, then paste into the same, another or a new project. Keep coordinates or place the copy on the map. Feature geometry, labels, style, descriptions and embedded marker assets are preserved; copies get new IDs and editable names. Clipboard survives reopening; paste supports Undo/Redo. Retains AP reference data, visibility/delete controls, black project labels, movable trays and 20 symbols. Browser and Android JS bridge tests pass; the native share chooser needs a physical-phone check. Run python3 build-web.py to verify baseline and overlays.
